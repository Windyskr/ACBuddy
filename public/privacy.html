ACBuddy 隐私政策

最近更新：2026-10-29 · 适用于 ACBuddy 浏览器扩展与 acbuddy.pages.dev 网站

ACBuddy 帮你记录在力扣（国内版 leetcode.cn、国际版 leetcode.com）上的刷题过程；在 codefun2000.com 和牛客（www.nowcoder.com）做题时，可以使用 AI 助手。本页说明扩展和网站处理哪些数据、存在哪里、发给谁，以及怎样删除。

扩展在力扣页面上做什么

  • 识别当前题目：读取页面地址和页面里的题目信息（题号、标题、难度）。
  • 识别判题结果：在页面内读取力扣判题接口的响应，以及运行、提交请求里的语言、代码和测试输入，判断这次提交是否通过。最近一次运行或提交的判题详情（用例的输入、输出和报错信息）只留在当前页面里供 AI 助手读取，刷新页面即清除，不上传到 ACBuddy。
  • 计算用时：只记录页面在前台时你最近一次操作键盘、鼠标的时间，不记录按了什么键、点了哪里。计时数据只存在本机，关闭浏览器即清除。
  • 自动重试：力扣提示「提交过于频繁」时，扩展在页面里按固定间隔重发同一个请求，最多 28 秒，不收集额外数据。
  • 在 codefun2000.com 和牛客的题目页上，扩展只在你向 AI 助手提问时读取当前题目的信息和代码框里的代码，不记录作答、不计时。
  • 扩展只读取 leetcode.cn、leetcode.com、codefun2000.com 和 www.nowcoder.com 的页面，不读取其他网页。

记到你 ACBuddy 账号里的数据

登录 ACBuddy 网站后，你每次在力扣提交，扩展会把以下内容记到你自己的账号：

  • 题目：所在站点（国内版或国际版）、题目标识、标题、难度
  • 作答：通过或未通过、判题结果（如「解答错误」）、本次用时、提交语言、力扣提交编号
  • 你在心得卡或网站上主动写的心得和笔记，以及在网站上设置的掌握程度、紧急程度、个人标签

扩展不会把你的代码上传到 ACBuddy。未登录时扩展不记录作答；不登录使用网站时，你的进度只保存在浏览器本地。

AI 助手（可选）

  • AI 助手默认不启用，需要你自己填写 AI 服务地址、模型和 API Key。
  • 你提问时，扩展会把对话内容、当前题目的题干，以及 AI 需要时读取的当前编辑器代码、最近一次运行或提交的判题结果、这道题在 ACBuddy 的作答记录和心得，发送到你配置的 AI 服务，并用你的 API Key 认证。
  • 这些内容不经过 ACBuddy 服务器；AI 服务如何处理数据，以该服务自己的隐私政策为准。
  • AI 服务配置（含 API Key）和对话记录只保存在本机浏览器的扩展存储里。对话可以在侧边栏删除，卸载扩展时会一并清除。

账号与登录

  • 网站账号保存用户名和密码散列（PBKDF2），不保存明文密码；账号另有一个系统生成的 API Key，用于程序化访问。
  • 登录状态通过会话 Cookie（acb_session，有效期 30 天）识别。扩展借用浏览器里的这个 Cookie 访问你的账号，不读取、不保存你的密码。
  • 为防止滥用，注册和登录按 IP 地址限流，相关计数按时间窗口过期并定期清理。

存储与共享

  • 账号数据存储在 Cloudflare（Pages 与 D1 数据库），全程使用 HTTPS 传输。
  • 只有登录你的账号才能看到你的数据。我们不出售数据、不投放广告、不做统计分析，也不把数据用于与刷题记录无关的用途。
  • 除托管服务 Cloudflare 和你自己配置的 AI 服务外，数据不会提供给任何第三方。

保留与删除

  • 数据会一直保留，直到你删除。
  • 在网站上可以删除单条作答记录，也可以清空笔记、星级和标签。
  • 如需删除整个账号及全部数据，请发邮件到 acbuddy@seek.li，核实后我们会删除。

联系我们

对本政策或你的数据有任何疑问，请发邮件到 acbuddy@seek.li。

政策变更

功能变化影响数据处理方式时，我们会更新本页并修改「最近更新」日期。
